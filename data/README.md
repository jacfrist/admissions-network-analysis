# Cleaned data

Generated by `python3 -m src.clean_data` from the raw files in `mimic-iv-data/`.
Do not edit these by hand; change `src/clean_data.py` and re-run it.

## Cohorts

| Cohort | `admission_type` values | Admissions | Patients |
|---|---|---|---|
| emergency | EW EMER., DIRECT EMER., URGENT | 157 | 83 |
| elective | ELECTIVE, SURGICAL SAME DAY ADMISSION | 31 | 27 |
| excluded | the four OBSERVATION types | 87 | – |

`in_strict_cohort` marks admissions that also fit the strict definition
(EW EMER. + DIRECT EMER. vs. ELECTIVE only), for a sensitivity analysis.
12 patients have admissions in both cohorts.

## Tables

**admissions_clean.csv**: one row per study admission (188 rows)
`subject_id, hadm_id, cohort, admission_type, in_strict_cohort, admittime, dischtime,
los_days, admission_location, discharge_location, hospital_expire_flag, gender, age,
n_diagnoses, path_length, n_transitions, n_distinct_units, first_unit`

- `age`: age at admission (`anchor_age` + years since `anchor_year`)
- `path_length`: number of care-unit stays; `n_transitions` = `path_length` − 1
- `discharge_location`: missing values recorded as `UNKNOWN`

**unit_stays.csv**: ordered care-unit stays for each admission (527 rows)
`subject_id, hadm_id, cohort, stay_seq, careunit, eventtype, intime, outtime, hours_in_unit`

**transitions.csv**: unit-to-unit moves, i.e. the network edges (337 rows)
`subject_id, hadm_id, cohort, from_unit, to_unit, transition_time`

## Cleaning steps

1. Excluded the 87 observation admissions.
2. Removed `discharge` rows from transfers (they mark leaving the hospital and have no care unit).
3. Removed transfer rows with no `hadm_id` (ED visits that did not become an admission).
4. Merged back-to-back rows in the same unit into one stay, so there are no self-loops.
5. Built transitions from consecutive stays. One admission has a stay in unit `Unknown`;
   its two transitions into and out of `Unknown` are dropped (not replaced with a made-up edge).

## Things to know before building networks

- **Entry units differ by cohort.** 109/157 emergency admissions start in the Emergency
  Department. 25/31 elective admissions start in the **Discharge Lounge**, which never
  appears as a final stay and lasts ~12 hours on median for elective patients, so it
  seems to act as a pre-admission holding area rather than a discharge area.
  Consider running the networks with and without these entry nodes.
